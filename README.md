# westquant-core

Common substrate for WestQuant Open integrations.

## v0.2 alpha

- typed WQIR representations across problem, operator, circuit, layout, control,
  hardware, execution and evaluation layers;
- RepGraph v0.2 DAG with explicit transformation provenance;
- framework-neutral plugin contracts;
- no dependency on WQT20 or any proprietary service.

WQT20 is a future proposer/value model over this substrate, not a hard runtime dependency.
